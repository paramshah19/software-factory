# Always-use documents

Put `.md` files here (or use **Always-use docs** in the dashboard). Every agent in every run reads them first and follows them: brand colours, design rules, tone of voice, naming, anything you always want.

Examples of what to write (one file each is fine):
- `brand-colours.md`: "Primary #FF5A36, background #0F1115, accent #7C5CFF. Rounded corners (12px). Never pure white."
- `design-rules.md`: "Dashboard first. Calm, friendly. Big tap targets. Always include dark mode."
- `preferences.md`: "No sign-ups. Everything works offline. Plain-language error messages."

This file (`README.md`) is ignored. Empty files are ignored.
